## 🏠 Home Lab

Mantengo mi propia infraestructura doméstica para pruebas y servicios de uso diario:

- **Node Central** — Raspberry Pi corriendo servicios en Docker.
- **Networking** — Mesh VPN con Tailscale para entrar de forma segura desde donde sea.
- **DNS & Privacy** — Pi-hole + Unbound bloqueando ads y trackers a nivel red.
- **Streaming** — Agregador de streaming self-hosted, con backend en FastAPI, un proxy en Go y transcodificación HLS.
- **Monitoring** — Monitoreo de disponibilidad de mis servicios, con notificaciones push si algo se cae.
- **Cloud Hybrid** — VPS en Oracle Cloud integrado a la red vía Tailscale.
